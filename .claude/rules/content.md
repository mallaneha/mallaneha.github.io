# Writing content

- Follow `docs/CONTENT.md` exactly. Don't invent frontmatter fields; the schema will reject them.
- Don't rewrite Neha's wording unless asked. Fix typos and broken formatting only.
- Never invent numbers, dates, employers or links. If something is missing, ask or leave a TODO.
- Code blocks need a language tag.
- Internal links are root-relative: `/writing/<slug>/`, not full URLs.
- New writing is `draft: true` until Neha says publish.
